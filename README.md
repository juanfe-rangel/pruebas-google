# Pruebas Google

Soluciones en Java para problemas de Google Code Jam. Cada problema está separado en su propia carpeta y usa una clase `Main`.

## Estructura

- `d1000000/Main.java` — D1000000
- `moons-and-umbrellas/Main.java` — Moons and Umbrellas
- `parenting-partnering-returns/Main.java` — Parenting Partnering Returns
- `chain-reactions/Main.java` — Chain Reactions
- `bathroom-stalls/Main.java` — Bathroom Stalls

Para ejecutar una solución, entra en su carpeta, compila y ejecuta:

```sh
javac Main.java
java Main
```

El programa lee los casos de prueba desde la entrada estándar.
